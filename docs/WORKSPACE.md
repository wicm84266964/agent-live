# 本地工作台

`npm start` 启动一个仅监听 127.0.0.1 的服务，负责页面、事件通道和 Codex 日志读取。
无第三方依赖，无构建过程。`npm run demo` 保留为静态预览，需要单独的 hook 才能连接实况。

## 使用

1. 启动服务后打开终端输出的地址。
2. 右上角选择需要观看的聊天。默认选择最近更新的会话，之后不自动切换。
3. 工具完成后，新日志记录自动进入战场和调用列表。
4. 「切换来源」可进入样本回放、导入协议文件或自定义本机 hook。
5. 「暂停」冻结当前战场，继续接收事件；「继续」后按接收顺序结算。
6. 方向明确的三类舰船分别代表读取、执行与长任务；未映射工具保留中性模型及计数。

会话发现目录默认为用户目录下 `.codex/sessions`。特殊部署可设置
`AGENT_LIVE_SESSIONS`。服务启动时可通过 `--file` 显式选择一个会话。
服务不会自动安装开机自启；停止进程后不再同步。

## 数据边界

- 当前 Codex 适配器只读取 CommandExecution / McpToolCall / FileChange 完成记录。
  开始时刻由真实完成时间减 duration 得到；看不到进行中的调用。
- 只接收启动读取之后的新增完整行；日志中的非工具记录跳过。
- 每 250ms 增量读取，最多每批 1MB，单行上限 16MB。半行和 UTF-8 分片保留至下一次读取。
- 单条坏 JSON、缺少状态或 ID 的调用会跳过并列入异常；日志截断、读取错误会停止读取并显示错误。
- 事件通道只发送调用名称、ID、成功状态和时间，不发送命令、参数、输出正文和聊天正文。
- SSE 会保留最近 1000 条事件用于恢复；游标由服务实例标识与序号组成，避免重连重复结算。
- 暂停缓冲上限 2000 条；超限明确断开。换源会清空缓存、统计、活动列表和特效。
- 活动列表保留最近 100 条调用，战斗保留最近 1000 条退场记录和日志，调用 ID 去重窗口为 10000 条。
  统计是当前页面这次连接的统计，不是完整 Codex 会话统计，也不提供持久化审计记录。
- 累计工具耗时是日志中显式耗时的合计，包含并行任务，不能视为墙钟运行时间。
- 未提供退出状态的事件不补成功；文件结束不补 `turn_end ok:true`。

## 视觉和操作

纵向卷轴星空、飞行航道与分层舰体采用程序化绘制，无外部图片或字体请求。
舰体的亮面、暗面、独立引擎和座舱由同一套几何与调色板生成。
我方战机在下方自动巡航，任务敌舰在上方出现；空档持续出现环境飞弹，并由自动驾驶横移规避。
环境飞弹以冷灰蓝色显示，任务敌舰采用暖色或紫色，页面明确标注环境飞弹不计战绩。
`flight-scene.mjs` 仅控制表现位置、弹道和规避，不生成协议事件，不修改成功、失败或调用数。
推进尾焰、星空卷轴、自动巡航和环境飞弹都不是智能体正在执行的证据。
任务敌舰结算仍然只来自真实结果；射击弹道是视觉表现，不能通过环境碰撞生成任务击杀。
暂停同时冻结巡航、环境飞弹和任务战场。
我方生命值为 100，环境弹命中扣 10、Boss 弹命中扣 18；受击产生护盾扩散、火花和飘字，随后保护 0.65 秒。生命最低锁定为 1，真实成功击杀每次回复 12，失败或重复结束不回血。
Boss 使用紫色瞄准散射弹持续攻击；我方命中逐步削减其表现装甲，最低保留 5%。装甲不是任务进度，只有真实成功结束才触发斩杀，失败仍单独结算。
持续交火需要数据源提供真实开始和结束事件；当前 Codex 完成记录源无法提前显示进行中的子智能体。支持生命周期的 HTTP 钩子和回放可显示完整交战。
在系统开启减少动态效果时默认使用柔和特效，也可在页面切换。

## 验证

运行 `npm test` 和 `npm run check`。新增回归覆盖增量读取、截断、坏记录、中文分片、
暂停缓冲、去重、SSE 游标恢复、恢复缺口和窄屏缩放。
旧验证中针对接地阴影及重复平移的断言已改为轨道签名和正确的世界原点旋转约束。
浏览器验收需要分别检查自动接入、暂停、样本回放、切回实况、错误提示和窄屏布局。
