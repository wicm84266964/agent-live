# 使用手册 · 实况智能体 agent-live

面向使用者（不是贡献者）。想改成自己的题材看 `docs/THEME.md`；
想把智能体接进来、字段怎么映射看 `docs/ADAPTERS.md` 与 `docs/PROTOCOL.md`。

---

## 0. 最短路径

```bash
npm run demo          # 打开 http://127.0.0.1:5173/
```

不用 `npm install`：仓库没有依赖，也没有构建步骤。

打开后：

- 点 **进入战场** → 立刻播仓库自带的真实样本战斗（292 次工具调用）。
- 拖一个文件进 **拖入分析文件** → 播你自己的会话。
- 先 `npm run hook`，再在 **连接 HTTP hook** 里点连接 → 实时看智能体干活。

## 1. 三个入口

### 1.1 一键演示（什么都不用准备）

播的是 `real-events.json` —— 由 `build-events.mjs` 从真实会话分析产物生成。
每次工具调用的出场时刻与死亡时刻，都是 `tool/call.time` 与 `tool/result.time`
相减得到的真值，不是编的节奏。

`real-events.json` 读不到时页面会**直接报错**，不会退回空表或假数据。

### 1.2 拖入分析文件

支持三种形态，**按内容判定，不看扩展名**：

| 形态 | 长相 | 典型来源 |
|---|---|---|
| `{meta:{...}, events:[...]}` | 一个对象，带 `events` 数组 | 本仓库 `real-events.json` |
| 纯事件数组 | `[{...},{...}]` | 任何按协议导出的事件列表 |
| JSONL | 每行一个 JSON | 各家智能体的会话日志（最常见） |

会话分析产物（`{turns:[{steps:[{tools:[...]}]}]}` 形状，如
`sample/session-analysis.json`）也直接支持：页面会按
`startTime` / `endTime` / `isError` 生成 event 与 tool_end 事件。

**拖入时会做的事：**

1. 剥掉 UTF-8 BOM（Windows 上 `Set-Content` / `Out-File` 默认会写 BOM，
   不处理的话第一行永远解析失败 —— 而那正好是会话的第一条事件）。
2. 每条事件过 `protocol/events.mjs` 的校验：缺 `kind` / 缺 `ts` 的记录**拒收并计数**，
   不会"修一修"塞进战场。
3. 时间轴做单调压缩（相邻间隔上限 1 秒），折叠掉多少毫秒记在 meta 里，可复算。

**拖入失败时**（形状认不出、不是 JSON、空文件、全是坏事件）：
面板上给出可读错误并说明支持哪些形态；左下角状态条变红写"载入失败 · 未播放任何数据"。
战场**保持原样** —— 不会偷偷回退成样本数据。

### 1.3 连接 HTTP hook（实时）

两个窗口：

```bash
# 窗口 1：钩子
npm run hook                      # 127.0.0.1:8787，只绑本机

# 窗口 2：页面
npm run demo                      # 127.0.0.1:5173
```

用 `npm run demo` 打开时，页面会把钩子地址改成**当前页面来源**
（默认 `http://127.0.0.1:5173`）。不要改回 8787：那是钩子自己的端口，
和页面不同源，浏览器会拦掉事件流。

**为什么不是 8787**：钩子服务（`adapters/http-hook.mjs`）刻意不发送
`access-control-allow-origin` 头。浏览器跨源读取 SSE 时会被拦掉响应体，
页面拿不到数据。所以 `npm run demo` 的静态服务同时把
`/event` `/events` `/stats` `/health` 反代到钩子端口，页面与钩子因此同源。

| 打开方式 | 实时流可用 | 说明 |
|---|---|---|
| `npm run demo` | ✅ | 已反代，同源 |
| `npm run serve`（python） | ⚠️ | 无代理 → 跨源，浏览器拦 SSE；页面如实报错，不回退样本 |
| 自己的静态服务器 | ⚠️ | 需自行反代，否则同上 |

钩子换了端口：`PORT=5300 HOOK_PORT=9000 npm run demo`。

**连上之前战场为空，连上之后才开始**。钩子出错时状态条写
"未伪造任何进度 / 连上才开始"，击杀数一个都不涨。

## 2. 自检：`npm run doctor`

页面和工作台用的是**同一个**校验器（`protocol/events.mjs`），
所以 doctor 的结论就是页面能不能播的结论。

```bash
npm run doctor -- --file ./my-log.jsonl
npm run doctor -- --stdin < my-log.jsonl
npm run doctor -- --file ./x.jsonl --profile cursor
npm run doctor -- --file ./x.jsonl --json > report.json
```

| 退出码 | 含义 | 下一步 |
|---|---|---|
| `0` | 通过：协议合法、id 全配对、无坏记录、无未知 kind | 可以接页面 |
| `1` | 语义不通过：配对不全 / 坏记录 / 未知 kind / 重复上报 | 按输出逐条修 |
| `2` | 源打不开或参数错 | 修路径或参数 |

实测（样本）：

```
  事件总数    585
  分类型      tool 292 / tool_end 292 / turn_end 1
  未知 kind   0
  坏记录      0
  id 配对     292/292（100.0%） 完美
  重复上报    0 个 id（多出 0 条）
  时间跨度    265.96s
  耗时分布    min 3ms / median 17ms / p90 597ms / max 42.22s（292 条，130 种不同值，合计 130.08s）
  结论        通过
```

## 3. 画面上每个数字都是什么

| 位置 | 显示 | 含义 |
|---|---|---|
| 运行态 | 敌 N | 当前场上存活的敌人数 |
| 运行态 | 击杀 N | 已由 `tool_end ok:true` 结算的调用数 |
| 运行态 | 连击 ×N | 连续成功次数（失败会打断，≥2 才显示） |
| 运行态警示 | 未映射 N | 工具名没匹配到任何品级规则 —— 非零就要去 `bestiary.mjs` 加规则 |
| 运行态警示 | 超时 N | 有调用超过预估时长 —— 它还活着，只是比预估久 |
| 按 I / 暂停 | 调用 N/292 | 已结算 / 总调用（进度用**调用数**，不用事件数） |
| 按 I / 暂停 | 同时最多 N | 真实最大并发度（样本是 4） |
| 按 I / 暂停 | 重复 N | 同一 id 的重复 `tool_end`，不重复计击杀 |

左下角**事件源状态条**：播的是哪份数据、多少条调用、拒收几条、坏行几条、未知 kind 多少。

## 4. 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停 |
| `P` | 暂停 |
| `R` | 重播（重播会清空全部累积计数，包括连击与重复） |
| `I` | 展开 / 收起明细层 |
| `F` / `S` / `N` | 受击闪烁 / 震屏 / 飘字 开关 |

## 5. 排错

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 拖入后提示"认不出这份文件的形状" | 文件是智能体的**原始**转录，工具块还嵌在 `content[]` 里 | 先摊平成协议形状，或写一份 profile（见 `docs/ADAPTERS.md`） |
| 拖入后提示"没有 tool（工具调用）" | 文件里只有 turn_end / 消息类事件 | 确认日志里有工具调用；没有就别编，如实报告 |
| 画面在动但敌人不出现 | 事件 `kind` 全落到未知（计入 unknownKinds） | `npm run doctor -- --file <路径>` 看 `未知 kind` 那一行 |
| 敌人出场了但永远不死 | `tool_end` 缺 `id`，配不上对 | doctor 会报"孤儿开始"；补 id |
| 血条空了敌人还活着 | **这是设计**，血条只是预估进度 | 无需处理 |
| 钩子连不上 | 没起 `npm run hook`；或地址填了 8787 | 地址填 `http://127.0.0.1:5173` |
| 钩子连上但没数据 | 上游没 POST，或 POST 被 400 拒了 | `curl http://127.0.0.1:5173/stats` 看 `accepted` / `rejected` |
| `npm run test` 报目录加载失败 | 用了 `node --test tests` | 必须用引号 glob：`node --test "tests/**/*.test.mjs"` |

## 6. 一条不能破的规矩

**画面动，必须有事件撑着。**

没有事件时画面什么都不发生；解析失败时停在原地并报错；
钩子断开时战场为空并说明原因。任何"为了让画面好看"而补的数据，
都会让这个工具从"观测"变成"表演" —— 那是它唯一不可接受的状态。

判断方法很简单：看左下角状态条。它说播的是哪份数据，就是哪份数据。
